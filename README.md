# ScheduleSage

ScheduleSage 是一款智能日程创建工具，它能帮助用户快速识别并导入日程到日历中。

## 核心功能

### 1. 多源日程导入

- 📋 剪贴板导入：自动检测剪贴板中的日程信息
- 📱 手动创建：直观的界面支持手动输入日程
- 🖼 图片识别：支持从图片中智能识别日程信息（OCR）

### 2. 智能识别

- 支持中文、英文、日文的多语言识别
- 智能解析时间、地点、标题等日程要素
- 自动识别重复日程模式

### 3. 便捷操作

- 拖拽图片即可快速识别
- 批量选择和导入日程
- 一键导入到系统日历

### 4. Pro 功能

- ♾️ 无限次数的 OCR 识别
- 🔄 批量导入功能
- 📊 更多高级功能持续开发中

## 技术特点

- 原生 SwiftUI 开发，确保流畅的用户体验
- 支持 macOS 系统日历集成
- 多语言本地化支持（中文、英文、日文）
- 优雅的拖放交互设计
- 模块化架构设计，易于扩展

## 系统要求

- macOS 14.0 或更高版本
- 支持 Apple Silicon 和 Intel 芯片
